# Контракт для агентов

Это самостоятельный публичный MCP-проект, а не копия `agent-dev-toolkit`.

- Сначала прочитай `README.md`, `SECURITY.md` и `docs/TOOL_CONTRACT.md`; сверяй код с актуальным SDK MCP.
- Всегда ищи существующую реализацию и выбирай минимальное изменение с доказательством корректности.
- Не объявляй `PASS` без реального вызова. Различай импорт Python-модуля, MCP `tools/list`, вызов MCP-инструмента и полноценный запуск EDA.
- Нельзя вводить произвольный shell/Tcl/DO/скриптовый исполнитель; отдельное архитектурное решение и тесты безопасности обязательны.
- Используй только публичные искусственные RTL/логи. Никаких файлов лицензий, закрытых исходников или телеметрии.
- Для Python-зависимостей используй `uv`; не меняй системное окружение пользователя. Обеспечивай переносимость на Windows/Linux.
- Для новой операции добавляй проверки ошибок, граничных значений и типов входных данных; поддерживай идемпотентный setup.
- Документация и инженерные пояснения — на русском; идентификаторы и общепринятые термины — на английском.
- Не копируй код стороннего проекта без проверки лицензии и указания происхождения.
