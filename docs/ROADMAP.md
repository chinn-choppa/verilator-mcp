    # Дорожная карта

    ## Bootstrap (текущий этап)

    - [x] Публичный интерфейс read-only диагностики без выполнения EDA.
    - [x] Установка через `uv`, инструкции, политика безопасности и CI.
    - [ ] Создать репозиторий на GitHub и включить Private Vulnerability Reporting.
    - [ ] Прогнать MCP Inspector и `tools/call` на Windows и Linux.

    ## Приоритетные этапы

    - [ ] M1: безопасное обнаружение Verilator и lint-only с реальным manifest/файлами проекта, без произвольных флагов.
- [ ] M2: сборка SystemVerilog testbench, изолированный каталог артефактов, запуск с timeout и явным exit code.
- [ ] M3: структурированные assertions, coverage, seed, история проверок и экспорты SARIF/JSON.
- [ ] M4: маршрутизация осциллограмм в Wavepeek/wave-mcp и поддержка Windows/MSYS2.

    ## Вопросы, требующие измерений

    - Поддерживаемые ОС и версии производителя, лицензирование, типовые форматы отчётов.
    - Время запуска и ресурсы (новый процесс против постоянной сессии).
    - Размер JSON MCP-ответа и токеновая нагрузка на агента.
    - Качество диагностики относительно прямого CLI на одинаковых открытых фикстурах.
    - Поведение при отмене, зависании, повреждённых данных и недоступной лицензии.

    Отдельные проекты `verilator-mcp`, `synplify-mcp`, `questa-mcp` развиваются параллельно и не требуют единого репозитория исполнения.
