# Совместимость

| Уровень | Ожидается | Подтверждено на момент создания |
| --- | --- | --- |
| Python | 3.11+ | Синтаксис проверяется локально на Python 3.13 |
| MCP | SDK v2, stdio | Нативная приёмка MCP `NOT_RUN` |
| Windows | Планируется | EDA `NOT_RUN` |
| Linux | Планируется | EDA `NOT_RUN` |
| Verilator | Разные версии, после исследования | `NOT_RUN` |
| Корпоративные проекты | Только в разрешённой среде | Не использовались |

Прототип не устанавливает EDA-бинарник и не проверяет его лицензию. Пользовательские версии инструмента выбираются явно через `VERILATOR_MCP_EXECUTABLE` или стандартный `PATH` только для безопасного обнаружения. В будущем запуск будет требовать отдельного разрешённого workspace.

Verilator не является полной заменой четырёхсостояниевой симуляции. Его успешный запуск не доказывает эквивалентность Questa.
